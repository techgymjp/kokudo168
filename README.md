# 酷道168号の星

国道168号を **枚方市 → 新宮市（約180km）** までバイクで疾走する、ブラウザで遊べる疑似3Dレースゲームです。

とろとろ走る車を追い抜き、狭い“酷道”区間でギリギリを攻めてくる対向車や崖から降ってくる落石をかわしながら、
チェックポイントで持ち時間を延ばしつつ新宮を目指します。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド不要・外部画像なし）。
ローカルサーバーで開く場合の例：

```sh
npx http-server -p 8080 .
```

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| ハンドル | ← → / A D | ◀ ▶ ボタン |
| アクセル | ↑ / W / Z / Space | アクセルボタン |
| ブレーキ | ↓ / S / X | ブレーキボタン |
| 一時停止 | Esc / P | ❚❚ ボタン |

- 日本は左側通行。遅い車は対向車線にはみ出して追い抜く
- 車や落石スレスレをすり抜けると「ギリギリ！」ボーナス（+0.5秒）
- 衝突・落石で転倒するとタイムロス、崖やガードレールにこすると減速
- 結果画面から X / LINE / Facebook / 端末の共有機能でシェア、結果画像の保存も可能
  （シェアURLは `js/game.js` の `SHARE_URL`：https://techgym.jp/column/claude-code-game-kokudo168/ ）

## 表示言語

日本語と英語に対応しています。端末の言語が日本語なら日本語、それ以外は英語で表示し、タイトル画面のボタンで切り替えられます（`js/i18n.js`）。
道路標識や看板など、風景に描かれた文字は日本の景色としてそのまま日本語です。

## Android アプリ

[Capacitor](https://capacitorjs.com/) で Android アプリにしています（パッケージ名 `jp.techgym.kokudo168`）。
ゲームのファイルはアプリに同梱しているので、通信なしでも遊べます（文字は端末のフォントになります）。

- 戻るボタン：プレイ中は一時停止、タイトル・結果画面ではアプリを終了
- 別のアプリに切り替えると自動で一時停止し、音も止まる
- シェアは Android の共有メニュー（X・LINE なども選べる）
- 広告（Google AdMob）
  - バナー：タイトル・一時停止・結果画面の下に表示（プレイ中は隠す）
  - インタースティシャル：「もう一度走る」「タイトルへ」を押したとき毎回
  - リワード：時間切れ（ゲームオーバー）のとき 1 ゲーム 1 回だけ「広告を見て、その場所から +20 秒で再開」
- タイトル画面にバージョンとプライバシーポリシー、EU などでは「広告の設定」

ビルドは GitHub Actions（`.github/workflows/android.yml`）で行います。
既定ブランチへの push で、動作確認用の APK（テスト広告）が Release `android-latest` に載ります。

```
https://github.com/techgymjp/kokudo168/releases/latest/download/kokudo168.apk
```

スマホで読み取る用の QR コード：`docs/apk-qr.png`

リポジトリの Secrets に署名鍵（`ANDROID_KEYSTORE_BASE64` など 4 つ）を登録すると、Google Play 用の署名付き AAB（本番広告）も Artifact に出力されます。

手元でビルドする場合：

```sh
npm ci
npm run android:sync   # www/ を作って android/ にコピー
npm run android:open   # Android Studio で開く
```

### Google Play の掲載情報

ストア用の画像（アイコン・フィーチャーグラフィック・日英のスクリーンショット）と紹介文の下書きは `docs/store/` にあります（`listing.md`）。

### 広告の設定

- AdMob のアプリ ID：`android/app/src/main/res/values/strings.xml` の `admob_app_id`
- 広告ユニット ID：`js/ads.js` の `production`（空欄の種類は本番ビルドで出さない）
- 動作確認用 APK はいつも Google のテスト広告。本番の広告は Google Play 用のビルド（`ADMOB_MODE=production`）だけで出る

## ファイル構成

- `index.html` / `css/style.css` — 画面・HUD・タイトル・結果画面
- `js/game.js` — 疑似3D描画エンジン、交通・落石・当たり判定、シェア機能
- `js/route.js` — 国道168号のコース定義（道幅・カーブ・勾配・名所の配置）
- `js/sprites.js` — 車・樹木・神社・大鳥居・吊り橋・標識・背景の山並みをキャンバスで手続き生成
- `js/audio.js` — WebAudio によるエンジン音・効果音
- `js/i18n.js` — 表示言語（日本語 / 英語）の翻訳表
- `js/ads.js` / `js/ads-config.js` — Google AdMob 広告（Android アプリのみ）と広告のモード（test / production）
- `js/build-info.js` — タイトル画面に出すバージョン（ビルド時に生成）
- `android/` — Android アプリのプロジェクト（Capacitor）
- `assets/` — アプリアイコンと起動画面の元画像
- `scripts/build-web.js` — Android に同梱する Web ファイルを `www/` にまとめるスクリプト

デバッグ用に `?stage=0`〜`?stage=7` を付けると指定区間から開始できます。
